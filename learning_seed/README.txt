This folder is a snapshot of about ten years of daily market closes (history/*.json) and the statistics computed from them (priors.json). The learning step copies it into _data/_learning only when it cannot download fresh history (for example when the data sites are blocked from the build machine) and never overwrites newer data. The files are plain data, never code. To regenerate on a machine with internet access, run: python learning_priors.py --make-seed  and commit the result.
